# Learning Cards

Each card has four layers: **L0** a twelve-year-old can follow → **L1** the mechanism → **L2** how to use it → **limit** when it fails. Plus the gap evidence.

---

## 迭代预算

> 改到什么时候该停？不设上限，一次小任务能吃光一天的额度。

### L21 · 迭代投入凯利

`iteration-kelly-sizer` · `components/L21-iteration-kelly-sizer/`

- **L0（人话）** 有把握就多投点，没把握就少投点，但永远别把全部力气押在一次上——因为你的「有把握」可能是错的。
- **L1（本质）** f* = (p·b − (1−p))/b，再乘分数系数 0.25 并封顶 15%。分数与封顶不是怯懦：模型估的 p 必然有偏，满凯利在 p 高估十个百分点时会把账户打到零（破坏遍历性）。
- **L2（怎么用）** 每轮投 budget×f，其余留作后续轮；负期望直接 0，不要「小注试试」。
- **边界** p 与赔率必须外部估；估错时分数系数只能缓解，不能纠正。
- **空白证据** 凯利公式在交易领域普及，但「按轮次分配 agent 预算」缺位（抽样 30 条邻域）。

### L22 · 计算预算期货

`compute-futures` · `components/L22-compute-futures/`

- **L0（人话）** 别把预算一口吃光，后面几轮还得活。这工具帮你留出「未来几轮够用」的钱。
- **L1（本质）** 用历史单轮成本的 90 分位（不是均值）× 剩余轮次预留。为什么用 p90：均值会让一半的轮次预算不够，而预算不够的代价是不对称的（半途而废）。
- **L2（怎么用）** 开工前算一次 reserve；can_spend_now ≤0（tight）就别承诺交付日期。
- **边界** 依赖历史成本样本；新任务首轮无样本，只能给保守上限。
- **空白证据** 云成本预测工具很多，但「按轮次 p90 预留并在本轮限额」的原语缺位（抽样未单列）。

### L23 · 深挖与铺开调度

`depth-breadth-scheduler` · `components/L23-depth-breadth-scheduler/`

- **L0（人话）** 手上三条线，钱只够认真做一条。这工具说：先深挖最有希望的那条，其余保持最小投入。
- **L1（本质）** 按边际收益贪心分配 + 单线优势判据（首项 >3× 次项则判 single-line）。贪心不是最优，但它是唯一能在不知道全局曲线时仍可解释的分法：每份预算都说得出为什么给它。
- **L2（怎么用）** 每轮重算；判 single-line 时立刻砍到只剩一条主线，别「都做一点」。
- **边界** 贪心不看未来轮次的耦合；多线强依赖时会误分。
- **空白证据** 多臂老虎机有理论方案，缺「给预算分配+解释」的工程原语（抽样未单列）。

### L24 · 边际收益钟

`marginal-value-clock` · `components/L24-marginal-value-clock/`

- **L0（人话）** 聊了半小时一点新东西都没有，就该换人接手，而不是继续聊到一小时后。
- **L1（本质）** 近 N 个样本的每分钟收益 < 阈值 → switch-operator。它把「脑暴三四轮归零就换执行者」这条经验变成可计算判据，而不是靠自觉。
- **L2（怎么用）** 开会/迭代时用时间戳+进度打点；判 switch 就换人，不加时长。
- **边界** 收益必须可量化；纯探索型工作用它会被过早叫停。
- **空白证据** 工时统计工具有，缺「按收益速率触发换人」的判定（抽样未单列）。
